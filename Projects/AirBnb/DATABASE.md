# Database Schema for AirBnb Project

## Models (Collections)

| Model Name  | Description                            | Fields                                                                                                                                                                                                                                                                                                                                        |
| ----------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Listing** | Represents a property listed on AirBnb | - `title`: String - The title of the listing<br><br>- `description`: String - A detailed description of the property<br><br>- `image`: String - URL of the listing image<br><br>- `price`: Number - Price per night<br><br>- `location`: String - Location of the property<br><br>- `country`: String - Country where the property is located |
