# Database Schema for AirBnb Project

## Models (Collections)

| Model Name  | Description                            | Fields                                                                                                                                                                                                                                                                                                                                              |
| ----------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Listing** | Represents a property listed on AirBnb | 1. `title`: String - The title of the listing<br><br>2. `description`: String - A detailed description of the property<br><br>3. `image`: String - URL of the listing image<br><br>4. `price`: Number - Price per night<br><br>5. `location`: String - Location of the property<br><br>6. `country`: String - Country where the property is located |
