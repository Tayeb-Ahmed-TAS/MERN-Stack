# Database Schema for AirBnb Project

## Models (Collections)

| **Model Name** | **Schema Name**   | **Description**                        | **Fields**                                                                                                                                                                                                                                                                                                                                                                                                                                                  | **File Link**                     |
| -------------- | ----------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| **Listing**    | **listingSchema** | Represents a property listed on AirBnb | 1. `title`: String - The title of the listing<br><br>2. `description`: String - A detailed description of the property<br><br>3. `image`: String - URL of the listing image<br><br>4. `price`: Number - Price per night<br><br>5. `location`: String - Location of the property <br><br>6. `country`: String - Country where the property is located<br><br>7. `reviews`: Array - List of reviews associated with the listing from the Review model<br><br> | [File Link](../models/listing.js) |
| **Review**     | **reviewSchema**  | Represents user reviews for listings   | 1. `comment` : String - The content of the review<br><br>2. `rating`: Number - Rating given by the user (1-5)<br><br>3. `createdAt`: Date & Time - Timestamp of when the review was created <br><br>                                                                                                                                                                                                                                                        | [File Link](../models/review.js)  |

## Relationships

| Sl  | **Model** | **Related Model** | **Type of Relationship** | **What it Represents**                                                                                        |
| --- | --------- | ----------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| 1   | Listing   | Review            | One-to-Many              | A single listing can have multiple reviews associated with it. Each review is linked to one specific listing. |
