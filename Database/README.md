# Database

**DataBase** is a collection of data in a format that can be easily accessed.

Databases can be classified into various types, such as relational databases (e.g., MySQL, PostgreSQL), NoSQL databases (e.g., MongoDB, Cassandra), and more.

## Why Databases?

- Can store large data.

- Features like security, scalability, etc.

- Easier to insert, update or delete data.

## DBMS (Database Management System)

A software that allows users to store, manage, and retrieve data in an organized way, making it easier to handle large amounts of information efficiently.

## SQL vs NoSQL

| SQL                                   | NoSQL                                                    |
| ------------------------------------- | -------------------------------------------------------- |
| Relational Databases                  | Non-Relational Databases                                 |
| Data stored in Tables                 | Data stored in document / key-value pairs / graphs, etc. |
| e.g., MySQL, Oracle, PostgreSQL, etc. | e.g., MongoDB, Cassandra, Neo4j, etc.                    |
